# 技术选型（架构决策记录）

> 状态：提案（待与《全网比价开源软件可行性方案.md》对齐后确认）　日期：2026-11-16

## 决策汇总

| 维度 | 选择 | 理由 |
|---|---|---|
| 语言 | **Python 3.11+** | 采集/API/数据处理生态最成熟；三个候选项目两个用 Python；AI Agent 集成（MCP）最顺 |
| HTTP 服务 | **FastAPI + Uvicorn** | 自带 OpenAPI 文档，异步 IO 适合多平台并发查询 |
| 数据模型 | **Pydantic v2** | 与 FastAPI 一体，统一各平台返回字段 |
| 存储 | **SQLite + SQLAlchemy**（本地优先） | 零部署成本，历史价格/搜索记录本地留存；后续可平滑切 PostgreSQL |
| HTTP 客户端 | **httpx** | 官方联盟 API 与聚合 API 调用，支持异步 |
| 浏览器采集（可选通道） | **Playwright** | 动态页面渲染兜底；默认不启用，不绕过任何验证 |
| CLI | **Typer** | 与 FastAPI 同生态，开发快 |
| MCP | **mcp（官方 Python SDK）** | 暴露 `compare_prices` / `price_history` 等工具给 AI Agent |
| 开源协议 | **MIT** | 最大化传播；避开 AGPL 传染（不引入 AgenticCPS 代码） |

## 架构：三通道 + 适配器

```
              ┌─────────────────────────────┐
              │  CLI / FastAPI / MCP Server  │
              └──────────────┬──────────────┘
                             │
                      comparator 聚合比价
                             │
        ┌────────────────────┼────────────────────┐
        │                    │                    │
  PlatformAdapter      PlatformAdapter      PlatformAdapter
   (taobao)              (jd)                 (pdd)
        │                    │                    │
   通道优先级：官方联盟 API → 聚合服务（大淘客/好单库）→ 网页采集（可选）
```

- **平台适配器（PlatformAdapter）**：每个电商一个，对外只暴露 `search()` / `detail()`，屏蔽通道差异。参考 AgenticCPS 的「平台适配器 + 供应商客户端」双层解耦，但用 Python 重新实现（不引入其 AGPL 代码）。
- **通道降级**：官方 API 未配置或失败 → 聚合 API → （显式开启时）网页采集。每次结果标注数据来源与口径，失败如实上报，不用缓存价冒充实时价。

## 排除方案记录

| 方案 | 排除原因 |
|---|---|
| fork AgenticCPS | AGPL-3.0 传染性，衍生作品须开源且 SaaS 场景受限；Java/Spring 全家桶对独立开发者过重 |
| fork PriceRadar（价探） | 许可证明确禁止未经授权的二次开发和商用 |
| 纯爬虫路线 | 反爬对抗成本高、合规风险大，无法商用化；仅保留为可选兜底通道 |
| 前端框架（Vue3 等） | M1-M3 阶段无必要，FastAPI 模板/静态页即可；M4 再评估 |
