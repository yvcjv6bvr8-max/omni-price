## 1. 淘宝联盟（阿里妈妈）

**步骤**：
1. 用淘宝账号登录 [pub.alimama.com](https://pub.alimama.com)，注册成为淘宝客（需支付宝实名）。
2. **媒体备案**：根据自身推广载体选择类型——
   - 网站：须已完成工信部 ICP 备案；
   - APP：须已上架应用市场；
   - 其他：社群/导购等，门槛最低，适合冷启动。
3. 备案审核通过后，进入淘宝联盟开放平台，右上角「新建应用」，**基于媒体备案生成 AppKey**（备案 ID 与 AppKey 一一对应）。
4. 在应用「管理」页查看权限包：基础 API（物料搜索、淘口令、转链）默认可自助申请；高级权限（渠道管理 relationId 等）为邀约制。

**产出物**：`TAOBAO_APP_KEY` / `TAOBAO_APP_SECRET` / 推广位 PID（填入 `.env`）

## 2. 京东联盟

**步骤**：
1. 注册 [union.jd.com](https://union.jd.com)（支持个人/企业），完成实名。
2. 媒体备案：网站（须 ICP 备案）/ APP（须软著+上架）/ 社交媒体（微博、公众号、抖音等，按粉丝量与认证要求）。
3. 登录 [jos.jd.com](https://jos.jd.com) 宙斯开发者中心创建应用，获取 `appKey` / `appSecret`。
   - ⚠️ **注意 2026 年新规**：京东开放平台要求创建应用提供软件著作权登记证书以证明自研能力（可使用关联公司软著但需关系证明）。个人开发者若暂无软著，可先：
     - 以联盟官网手动创建推广位 + 聚合服务商（好单库支持填 unionId 与三段式 PID 转链）过渡；
     - 或申请软著（普通登记约 1–3 个月，加急更快）。
4. 创建推广位，得到三段式 PID：`unionId_siteId_adzoneId`。

**产出物**：`JD_APP_KEY` / `JD_APP_SECRET` / `JD_UNION_ID` / `JD_ADZONE_ID`

## 3. 多多进宝（多多客）

**步骤**：
1. 注册 [jinbao.pinduoduo.com](https://jinbao.pinduoduo.com) 多多客账号（个人/企业均可），完成实名。
2. 登录 [open.pinduoduo.com](https://open.pinduoduo.com) 创建应用，类型选「普通自研系统开发者」——**不涉及保证金**，适合个人与小团队。
3. 创建推广位（PID）；商品搜索、转链、订单查询等基础接口直接可用，部分高级权限包需单独申请审核。

**产出物**：`PDD_CLIENT_ID` / `PDD_CLIENT_SECRET` / `PDD_PID`
