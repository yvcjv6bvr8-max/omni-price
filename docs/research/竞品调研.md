# 竞品调研：全网比价开源项目

> 调研时间：2026-11-16　渠道：GitHub 仓库搜索 + README 精读

## 结论先行

**没有可以直接 fork 的现成项目**：功能最全的 AgenticCPS 是 AGPL-3.0 强传染性协议且为 Java 重型架构；形态最接近的 PriceRadar（价探）明确禁止二次开发和商用；MIT 的 price-compare-skill 太轻量（单文件爬虫）。因此**自研 + 参考三家之长**是正确路线。

## 关键洞察

1. **官方 API vs 爬虫是核心路线分叉**。AgenticCPS 证明了「官方联盟 API + 聚合兜底」是可落地的工程化路线，且能顺带获得 CPS 佣金；纯爬虫路线（price-compare-skill、PriceRadar）面临反爬与合规风险，适合个人工具但难做产品。
2. **联盟准入门槛是个人开发者的最大障碍**（详见《联盟账号注册清单》）：京东 JOS 2026 年起要求软著、多多进宝部分接口要保证金、淘宝高级权限邀约制。AgenticCPS 给出的解法是**大淘客/好单库/聚推客零门槛聚合 API 兜底**，我们采纳。
3. **MCP 入口已成标配**：AgenticCPS 和 PriceRadar 都提供 MCP Server，AI Agent 调用比价工具是明确趋势，本项目保留该入口。
4. **合规设计是加分项**：PriceRadar 的「不绕过验证、不用历史价回填失败、明确标注数据口径」原则直接纳入本项目设计约束。
